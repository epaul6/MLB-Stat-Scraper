# MLB Stat Scraper
Scrapes 2020 splits from Baseball Reference and displays them on screen. The results may be a bit jumbled at times so it also will write splits for the 2020-2017 seasons into separate sheets in an Excel file. 
The file will be named with whatever player you chose to scrape. Also, it will write additional sheets for 2020 Statcast data of said player and league-wide exit-velo's for the 2020-2017 seasons.


### Installation

```install
$ git clone https://github.com/epthewizard/MAC-Scanner.git
$ cd MAC-Scanner
$ python3 -m venv venv
$ source venv/bin/activate
$ pip3 install -r requirements.txt
```
